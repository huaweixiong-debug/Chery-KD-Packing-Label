# 奇瑞 KD 装箱标签二维码生成器

根据奇瑞 KD 装箱技术通知，按固定前缀规则生成纸箱标签二维码（桌面 GUI）。

## 二维码内容格式

```
10#{零件号}$ 11#8KN$ 17#{包装数量}$ 18#{发运批次}$ 19#{码放层数}$ 20#{生产日期}$ 31#{纸箱唯一码}$ PK#{纸箱编号}$
```

- 供应商代码固定为 `8KN`
- 字母统一为大写
- 每个 `$` 后保留一个空格（与技术通知示例一致）

## 环境要求

- Python 3.8+
- Windows / Linux / macOS 均可

## 安装

在项目目录下执行：

```bash
pip install -r requirements.txt
```

建议使用虚拟环境：

```bash
python -m venv .venv

# Windows
.venv\Scripts\activate

# Linux / macOS
source .venv/bin/activate

pip install -r requirements.txt
```

## 运行

```bash
python main.py
```

## 使用说明

1. **选择零件**：下拉菜单显示「客户件号 — 零件名称」，选中后自动填充包装数量、纸箱编号、纸箱唯一码。
2. **操作员工**：从下拉菜单选择。员工名单在 `employees.txt`，每行一个姓名，可自行增删。
3. **包装数量**：默认取表格「包装收容数」，可手工修改。
4. **发运批次**：手工填写。
5. **码放层数**：手工填写。
6. **生产日期**：默认当天，格式 `YYYYMMDD`，可改。
7. **纸箱唯一码**：按零件前缀预填（如 `A0001`）。点「取下一唯一码」或生成成功后会自动递增（`A0001` → `A0002` …）。已用编号保存在 `data/counters.json`，重启后仍唯一。
8. **纸箱编号**：只读，随零件带出。
9. 界面实时预览二维码字符串。点「生成二维码」后：
   - 在 `output/` 保存二维码 PNG
   - 同时保存一张标签预览图
   - 右侧显示二维码与约 100×70mm 标签示意

## 常见问题

- **中文标签预览乱码 / 方块字**：系统缺少中文字体时可能发生。Windows 一般自带微软雅黑；Linux 可安装 `fonts-wqy-microhei` 等。二维码内容本身不受影响。
- **唯一码重复**：请勿手工回退已用编号；`data/counters.json` 记录各字目前缀已用最大值。
